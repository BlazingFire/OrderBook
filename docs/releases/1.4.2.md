# OrderBook 1.4.2

Released 2026-10-05. Signed with the release key `release-2026-10-01`. Setup installers only.
Download: <https://github.com/BlazingFire/OrderBook-Releases/releases/tag/v1.4.2>

## Install order

As before:
1. Install the Master Setup over the existing install first. There is no need to uninstall
   it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7.
3. From then on, updates are automatic.

## What changed

- **English only.** The app now has a single language.
  - The second language, the language choice, and its PDF font have been removed.
  - A PC that had the other language saved now simply shows English.
  - Text typed in another script (for example a party name) no longer prints in PDFs.
- **Filter strips no longer cut off dropdowns.**
  - On narrow screens the filter strip above a list now wraps onto a second row instead
    of scrolling sideways.
  - Opening a filter dropdown (for example Role on the Users screen) no longer hides the
    search box.
  - Date boxes stay a compact width.
- **Office panels list.** A panel's status labels sit on one line, and the "Paired" and
  "Last seen" times are shown in full.

## Compatibility

- An Office still on 1.4.1 keeps working with a 1.4.2 Master until it updates.
- Report PDFs it asks for come back in English.
