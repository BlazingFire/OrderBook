# OrderBook 1.5.5

> A second, unsigned 1.5.5 was also built on the other device from
> `feat/pdf-15x` (printroom PDF bundle: the order record's third button, the
> fixed-layout final-order PDF, panel protocol 11 → 12). It was never
> published to the releases repository; the signed build above is the
> released 1.5.5.

Built and signed on the release PC (`release-2026-10-01`). Local build, not pushed to git.

This release carries everything since 1.5.3: the numeric-variant coded-half fix,
the Rust sidecar (core, helper, bridges, 4 wired paths with parity tests), and
the duplicates-styles cleanup. No migration, no panel protocol change: every
Rust call falls back to the TypeScript implementation when no helper binary is
present, so behaviour is unchanged.

## Install order

As before:

1. Install the Master Setup over the existing install first. There is no need to uninstall it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7. The Master carries the Office setup of
   its own version, so its Offices can update with no internet.
3. From then on, updates are automatic.

## What changed (since 1.5.3)

### Order note: numeric variant codes print coded-right

An alphanumeric sub product (e.g. 18X14 VITROSA SET) with numeric-only variant
codes (1501-1510) now renders coded-right under a "category - sub product"
heading instead of named-left. Preview, print, PDF and printroom inherit it
(all read the shared model).

### Rust sidecar: core, helper, bridges, 4 wired paths

The `rust/` workspace (csv, pick-score, record match/filter, spreadsheet parse,
manifest payload, HLC clock, LWW merge, line identity, import-row parse) plus
the `orderbook-helper` sidecar, with TypeScript bridges in Master and Office.
Four wired paths (log CSV export, offline pick ranking, sheet read, import
sheet batch) with parity suites. Behaviour unchanged without a helper binary:
every call falls back to TypeScript. Docs for the last mile: install the
Windows SDK on the build machine so the helper binary can link
(`winget install --id Microsoft.WindowsSDK.10.0.26100 --silent
--accept-package-agreements --accept-source-agreements`), then
`cargo test --manifest-path rust/Cargo.toml`.

### Cleanup: duplicate-list styles to the shared kit

The Master-only `.ob-dup*` section moved to the kit's `ui/src/base.css` so both
panels render the duplicates tab; 5 dead i18n keys removed.
