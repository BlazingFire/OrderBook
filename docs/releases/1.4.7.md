# OrderBook 1.4.7

Released 2026-10-10. Signed with the release key `release-2026-10-01`. Setup installers only.
Download: <https://github.com/BlazingFire/OrderBook-Releases/releases/tag/v1.4.7>

This release brings together everything built since 1.4.6: the product backup and restore in one zip, the
New Order record and party details screens, the To-do list, Sell today, the person screen, the notification
drawer, and the Office setup carried inside the Master's.

## Install order

As before:
1. Install the Master Setup over the existing install first. There is no need to uninstall it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7. The Master now carries the Office
   setup of its own version, so its Offices can update with no internet.
3. From then on, updates are automatic.

An Office on 1.4.6 or older must update to 1.4.7 to keep working with a 1.4.7 Master (panel protocol 11).

## What changed

### The OrderBook icon

- Every program file shows the OrderBook mark, never Electron's logo: the Master and Office panels (window,
  taskbar, Start menu and desktop shortcuts, Explorer) since 1.4.5, and now the Clean Install tool too.
- The Master installed on this PC is still 1.4.4, from before the icon was stamped into the program file, which is
  why it shows Electron's logo. Installing 1.4.7 over it replaces the icon.

### Products: backup and restore in one zip

- **Products › Sub products › Backup products (.zip)** writes the whole catalogue in one file: the products
  sheet, main products, colours, brands, photo captions and every photo, named after the product codes.
- **Restore from .zip** reads it back, shows what will change first, and changes only that. It also takes the
  plain products sheets (.csv / .xlsx) that 1.2.4 to 1.4.6 exported.
- Colours, photos (exact bytes, order, captions, main photo), weights, sizes, aliases, variants, brands and the
  order of products all come back exactly as they were. The same zip restored twice changes nothing.
- Two backups can be combined: a product is matched by code, then by name, so no product appears twice.
- **Make the catalogue exactly this file** (off by default) moves to the Recycle Bin whatever the file does not
  list, so a new install can be made equal to a backup.
- **Updates change no data.** The catalogue that ships with the program loads only on a new install that has not
  been set up; an update never adds, removes or changes products or photos.

### New Order and its record

- "Pending Order" is called **New Order** everywhere.
- A new order opens on a new record screen, the same on both panels: the party, phone, city, source and follow-up
  at the top; the lines with a band for lines missing a weight and **Add weights**; Convert with its checks;
  notes and history; a stage menu, Copy number, Share, and **Print & PDF** (Filling note, Dispatch note, PDF).
- New Order entry walks product, sub product, colour, quantity, packaging, grade and back by Enter; Shift+Q goes
  to a new product. The sub product list is clearer and can be collapsed.
- The New order and Final order lists have a **Notes** column and an **Action** column (edit, and delete on the
  Master). Delete moved from the ⋯ menu to a button in the record's header.

### Parties

- A new party details screen on the Master: the orders of the party (New / Final), party-wise product names with
  Add name, who can reach the party, and the details. **New order** from it opens New Order on that party.

### To-do list

- The Lists menu is now the **To-do list**. An administrator writes a task, with an expiry if wanted, and deletes
  it. Everybody marks a task In progress or Completed, and sees who marked what and when.

### Notice board, Sell today, Basic Home

- Settings decide whether notices show on Basic Home and at sign-in; each notice says where it shows.
- **Sell today:** a pop-up after sign-in with today's products and a message, closing by itself after the chosen
  seconds, managed in Notice board management.
- A product slideshow beside the notice band on Basic Home. The notice card has a reading width and a clear
  **Open** button.

### People, notifications, keys

- A new person screen in Roles & users: details, password reset, deactivate, delete, and what a role change gains
  or loses.
- Notifications open in a drawer from the right, grouped by day, with filters and Mark all as read.
- **Escape** goes back in every screen (it asks before dropping typed work) and leaves a New Order with work in it
  alone.
- Office panels can be set up from the Master (Office panels › Add panel), with the setup file downloadable there.
