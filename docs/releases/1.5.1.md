# OrderBook 1.5.1

Released 2026-10-14. Signed with the release key `release-2026-10-01`. Setup installers only.
Download: <https://github.com/BlazingFire/OrderBook-Releases/releases/tag/v1.5.1>

This release adds the **Delete data** screen to the Master.

## Install order

As before:
1. Install the Master Setup over the existing install first. There is no need to uninstall it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7. The Master carries the Office setup of
   its own version, so its Offices can update with no internet.
3. From then on, updates are automatic.

No database change: 1.5.1 adds no migration. A 1.5.0 Office keeps working with a 1.5.1 Master.

## What changed

### Delete data (Master, Admin menu)

Only an administrator or a Server Master who can manage settings sees it.

- **Start fresh:** deletes every new order, final order and party, for every user, every office panel and the
  Master, so the company can start again. Products, users, roles, settings, office panels and the activity log
  stay. Order and party numbers carry on from where they were, so a printed PO number is never used twice.
- **Delete all chat messages:** empties every chat; the groups and who is in them stay.
- **Clear print room history:** deletes printed and cancelled jobs; jobs still waiting or printing stay.
- These three show what will be deleted and what is kept, then ask for your own password and the word `DELETE`.
  They cannot be undone and nothing goes to the Recycle Bin: take a backup first.
- **Find and delete one record:** search parties, new orders and final orders and delete just one, to the
  Recycle Bin.
- **Delete related data** (a switch, off unless turned on): deleting a party on the Master first lists every new
  and final order it has, then sends them to the Recycle Bin with the party. Restore the party first, then its
  orders. Off, a party that still has orders cannot be deleted, as before. A party deleted from an Office panel
  works as before.
