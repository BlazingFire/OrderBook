# OrderBook 1.4.1

Released 2026-10-04. Signed with the release key `release-2026-10-01`.
Download: <https://github.com/BlazingFire/OrderBook-Releases/releases/tag/v1.4.1>

From this release on, only **Setup** installers are published. There is no Standalone
`.exe` any more, and the release page holds only the three Setup files and the update
manifests.

## Install order

1. **Master PC first.** Run `OrderBook-Master-1.4.1-Setup.exe` over the existing
   install. Do not uninstall the old one first: the data is kept.
2. **Then each Office PC.** Run `OrderBook-Office-1.4.1-Setup.exe`, or
   `OrderBook-Office-Win7-1.4.1-Setup.exe` on a Windows 7 PC, the same way. An Office
   that is on a different version from its Master waits on "Update needed" until it
   is updated.
3. From then on, updates are automatic. The Master checks GitHub every few minutes and
   installs its own update at night (23:00 by default), and every Office takes its
   update from the Master.

## What is new: connecting an Office PC to the Master

**On the Master (Office panels → Add Office Panel)**

- The card shows how long the pairing window stays open, and says so plainly when it
  has closed.
- If automatic joining is switched off, the card says so before you press anything,
  explains that Offices must use the pairing password, and links to the setting.
- The card lists this Master's network addresses, so an Office can connect by address.
- The Master tells each Office the address that is on that Office's own network.
  Before, a PC with several network adapters could hand out an address the Office
  could not reach.
- The Master starts even when its search port is busy. Connecting by address still
  works then, and the screen says why automatic search is off.
- A PC that was removed and then connected again gets its old row back, with its name,
  device code and history, instead of a second row. Old removed rows are hidden behind
  "Show removed".
- Two panels can no longer have the same name.
- "Reissue secret" gives a connected panel a new secret, after a confirmation.
- Too many wrong pairing passwords now gives a clear "wait N seconds" message.
- The Windows firewall rules are no longer added again on every update.

**On the Office (the connection screen)**

- Searching shows how long it has been looking, and it can be stopped.
- Every failure says what went wrong and what to do next, and names the Master it
  found. It tells apart:
  - the window being closed;
  - automatic joining being off;
  - a wrong password;
  - too many attempts, with a live countdown;
  - an address that is not a Master Panel;
  - an address that does not answer;
  - a bad address.
- **Test connection** checks an address before pairing and shows the Master's version.
- The last address is remembered, and the first sync shows its progress.
- When the Master removes this PC, the Office shows "This PC was removed by the Master
  Panel" at once, and keeps showing it after a restart.
- **Unpair:**
  - unpairing tells the Master, so its list stays right;
  - without signing in, unpairing is only possible when the Master cannot be reached
    or no longer recognises this PC;
  - discarding unsent work always needs a signed-in user with the right permission.
- Security: a PC's old pairing secret is sent only to a Master that first proves it is
  the same Master. Typing a wrong address can no longer leak it.
