# OrderBook 1.5.3

Not yet released: committed and pushed to `main` so the panels can pick it up;
Setup installers still to be built and signed with the release key
`release-2026-10-01`.

This release covers the order notes and the product catalogue: Dispatch note
column ticks that stay saved, order totals on every note page, the note
buttons directly on the lead screens, a calmer default note look, a product
edit that patches pending lines without rewriting history, and a per-row
review for product imports.

## Install order

As before:
1. Install the Master Setup over the existing install first. There is no need to uninstall it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7. The Master carries the Office setup of
   its own version, so its Offices can update with no internet.
3. From then on, updates are automatic.

One additive database change: 1.5.3 remembers each record's Dispatch note
column ticks (nullable columns, nothing rewritten). No panel protocol change:
a 1.5.2 Office keeps working with a 1.5.3 Master.

## What changed

### Dispatch note column ticks, saved (Filling / Dispatch note)

The Dispatch note screen's Packing / Grade / Colour tick boxes are now saved
on the record with a Save button, and every rendering — preview, print, PDF
and the print room — prints exactly the saved choice. An unticked column
vanishes everywhere. Filling note always prints all three, as before.

### Order totals on every note page

The Filling and Dispatch notes and their PDFs now show the order totals on
every page (TOTAL), instead of per-page figures.

### Note buttons directly on the lead screens

The Master lead screen and the Office lead board show Filling note, Dispatch
note and Preview PDF directly, instead of a Print and PDF menu. Preview PDF
needs the export permission, and on the Office only for a synced lead. The
note buttons stay hidden after a lead is converted, as before.

### Calmer default note look

Notes print bold by default (a company switch, on unless changed), so strip
figures and headings read at a glance. The toolbar Bold box still overrides
per note.

### Product edit that respects history

Editing a product patches the snapshot columns of pending leads and
undispatched orders in one go, while dispatched orders and converted leads
keep the snapshot taken on the day. The conflicts screen shows what will be
patched and what stays frozen, with a before/after list. Saving an unchanged
product writes nothing.

### Per-row review for product imports

A product import file is reviewed row by row: each row shows the file values
beside the existing values with an auto decision (create, update or skip) and
a reason. Unchanged rows default to skip, and nothing ever auto-deletes.
Applying runs only on the reviewed selection.

### Duplicates folded into the conflicts screen

The old Duplicates page is gone: the product conflicts screen has a
Duplicates tab with the same finder inline, so there is one copy to keep.
