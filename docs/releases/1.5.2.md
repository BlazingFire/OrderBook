# OrderBook 1.5.2

Released 2026-10-20. Signed with the release key `release-2026-10-01`. Setup installers only.
Download: <https://github.com/BlazingFire/OrderBook-Releases/releases/tag/v1.5.2>

This release adds **Save to this device** on the Filling and Dispatch notes.

## Install order

As before:
1. Install the Master Setup over the existing install first. There is no need to uninstall it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7. The Master carries the Office setup of
   its own version, so its Offices can update with no internet.
3. From then on, updates are automatic.

No database change: 1.5.2 adds no migration. A 1.5.1 Office keeps working with a 1.5.2 Master.

## What changed

### Save to this device (Filling / Dispatch note, desktop app only)

Beside Print, a new **Save to this device** button saves the note straight to the Desktop as a PDF, with no
dialog. A repeat save never overwrites the last one: the name grows into a series (`PO-…-dispatch.pdf`,
`PO-…-dispatch (2).pdf`, …). A toast names the file it wrote.

The button shows only in the installed desktop app. A browser tab cannot write outside its downloads, so there
it stays hidden and the existing Save PDF (with its dialog) is unchanged.
