# OrderBook 1.5.6

Built and signed on the release PC (`release-2026-10-01`).

This release closes the remaining 1.5.3 audit gaps, brings the Arc UI kit to
both panels, and hardens the product-conflicts tab with a full conflict
catalogue. No migration, no panel protocol change.

## Install order

As before:

1. Install the Master Setup over the existing install first. There is no need to uninstall it; the data is kept.
2. Then install each Office Setup, or the Win7 Office Setup on Windows 7. The Master carries the Office setup of
   its own version, so its Offices can update with no internet.
3. From then on, updates are automatic.

## What changed (since 1.5.5)

### Audit fixes: orders Preview PDF, PDF headings, printroom bold

- Final-order records on both panels have Preview PDF (`GET /api/orders/:id/pdf`,
  gated on `orders.export`), closing the gap where only leads had it.
- The Master PDF gates PACKING/COLOUR/GRADE headings on the saved tick boxes,
  exactly like the preview — an unticked column no longer prints an empty-headed column.
- Bold travels frozen in the NoteDocument, so the printroom honours
  `notes.defaultBold=false`.

### Product conflicts: full catalogue + new detections

`docs/PRODUCT_CONFLICTS.md` lists every way product records can conflict (26
possibilities in 6 families). New in the software:

- **Near-name and code-variant suspects** in the duplicates finder (likely
  typos like `DAMRU`/`DAMRUU`, `OPT-0001`/`OPT-001`) — grouped for review,
  never auto-deleted; resolving a suspect-only group is refused with a message.
- **Quality tab** on the conflicts screen: orphan colours, size-format drift,
  alias clashes, colour-rule contradictions — computed client-side over the
  loaded catalogue, fixed on the product.
- **Import rename/move suspects** in the dry-run review (same name, different
  code or different product), defaulting to Skip.
- **Retire guard**: deactivating variants quoted by pending lines is refused,
  naming the codes.

### Arc UI kit, both panels

`docs/ARC_COMPONENTS.md` is the applicability map. Shipped natively in the
kit (no new deps, offline-safe, reduced-motion branches):

- Buttons: press scale, label morph, `loading` alias; ActionButton (pending →
  Saved), HoldToConfirm, CopyButton (replaces 3 ad-hoc copies), ButtonGroup
  (note-screen actions).
- SearchField on every list filter (clearable, Esc-clear, `/` chord);
  UserMenu in both footers (account, theme, motion, change password, sign out
  with progress); SwipeActions on chat, print-job and notice rows (always with
  a More menu); Reactions on the notice board; animated sidebar (width, chevron
  rotation, staggered submenus).

### Dashboard

`docs/ARC_COMPONENTS.md` applicability + `ui/src/Dashboard.tsx` kit:
colour tiles with animated figures and sparklines, animated pipeline bars,
donut with drill-down, drill cards that open the record. Both panels show live
figures; every tile navigates to its screen; still no chart library and no
money anywhere.
